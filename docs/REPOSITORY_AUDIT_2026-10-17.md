# 课题组爬虫总仓库：发布前深度审计

审计日期：2026-10-17
审计对象：`research-crawlers-and-datasets`（12 个目标，私有仓库）
原则：只检查发布副本和离线测试，不访问目标站点、不尝试登录、不运行真实抓取、不改变原始采集文件。

## 结论

**私有课题组使用：有条件通过。直接转换 Public：暂不通过。**

- 250 个数据清单条目与 407 个来源清单条目已做 SHA-256 / 文件路径校验；Git LFS 用于保存大型表格。
- 253 个 Python 文件均可做 AST 语法解析（含本轮新增的发布工具和测试）；这并不代表 253 个脚本都能直接运行。
- 外包/招聘引擎已通过 193 个选定的离线测试、54 个子测试；Facebook 通过 97 个离线测试、49 个子测试。未执行登录、设备控制或实时爬取。
- Keep 的阶段 1 分享版发现过超出脱敏范围的 URL/标识字段，**本次已以科研字段白名单重新投影 206 个 JSON**；阶段 2 改为单一可复现脚本，且匿名评论 ID 使用确定性算法。之前已推送的 Git 历史仍然需要独立清理。
- 部分上传数据是第三方字幕、影评、网站页面内容及真实任务信息；现有仓库**未证明这些材料获得公众再分发授权**。不应因仓库 Private 可用就推论能公开发布。

## 本轮仓库级修正

1. **Keep 阶段 1 隐私白名单**：移除所有非研究必需字段，例如图片和会员链接、页面 Schema、视频地址、未知用户标识、评论正文。原始抓包没有修改。
2. **Keep 阶段 2 可复现**：`tools/normalize_keep.py` 固定文件遍历顺序、合并重复动态、使用稳定的匿名评论 ID；`tools/keep_release.py` 是今后的唯一发布数据投影入口。旧匿名评论 ID 不能跨版本互认。
3. **Keep 发布来源清单**：不再暴露原始 JSON 文件名或其 SHA-256；`metadata/data-manifest.json` 使用通用来源描述。
4. **发布校验增强**：`tools/verify_release.py` 同时检查数据和源码清单。
5. **Keep README**：重写运行命令与阶段定义，标记历史数据和代码局限。

## 未解除的问题与优先级

### P0：公开前必须处理

- **Git 历史**：先前的 Keep 匿名 JSON 含可指向用户内容的 URL、未白名单过滤的字段。虽然最新版本已修复，但 Git 历史/LFS 旧对象不会随最新提交的覆盖自动消失。公开前须制作经过复核的全新、干净发布历史，并评估需要对旧对象执行 GitHub 平台端清理。
- **第三方数据再分发权**：B站字幕、豆瓣影评以及各平台的原文信息不具备自动的公众再分发许可；公开前要决定仅发布代码、统计摘要或获得授权的数据，不应直接公开全部研究数据。
- **依赖版权/许可证**：总仓库及若干引入的第三方组件许可归属尚未逐一厘清。不能在不确认权属的情况下统一添加 MIT 或其他开源许可证并声称覆盖所有文件。

### P1：课题组可靠复现

- **招聘溯源**：前程无忧完整原始层缺失，BOSS 源 ID 归档不含 JD，猎聘 46,607 条最终层还缺完整原始记录配对证据。
- **价格/时间证据**：一品威客 sitemap 更新时间候选与真正任务发布日期应区分；猪八戒采集仅列表内容，非报价真值。
- **Amazon 缺失与冲突**：月销量 6,134 行为空，月评论留评率 130,399 行为空；上述 29 条冲突需按原始请求/时间版本核查。
- **无生产验收**：B站/豆瓣/Keep 第一阶段、Amazon 历史代码、Facebook Android 及七站采集均未在当前网站环境完成全链路验收。

### P2：文档和维护

- 历史 `projects/market-platform/docs/ORIGINAL_README.md` 与引入的 `boss_cdp` 文档曾有约 12 个断链；本轮已修正相对路径、改成归档提示或指向总仓库 Issues。仍建议优先阅读当前的项目 README。
- GitHub Actions 自动校验目前仅是 `docs/optional-ci-workflow-template.yml` 文档模板，未启用真正的 Actions 工作流。
- Amazon、B站、豆瓣历史脚本有不同环境依赖和绝对路径；使用者需在独立虚拟环境安装缺失包，不能直接批量运行所有历史脚本。
- `tools/build_repository.py` 面向维护人员的本机桌面源目录，不是课题组成员首次运行的入口。

## 课题组建议验收命令

在仓库根目录：

```bash
git lfs install
git lfs pull
python tools/verify_release.py
python tools/normalize_keep.py --input projects/social/keep/data/phase1_anonymized --output ../keep-rebuilt
```

七站共用引擎：进入 `projects/market-platform/` 后执行 `python run.py --help`，随后在不发网络请求的测试范围内运行 `python -m pytest -q tests`（正式全套测试应按模块筛选以避免设备/联网测试）。

Facebook：进入 `projects/social/facebook/source/`，运行 `python -m pytest -q` **仅限经过复核为离线的测试集合**。本次已验证若干明确的解析/API/安全/分页测试；不要默认把全部测试都当成无网络测试。

## 当前发布决策

**保留 Private，允许课题组中具备访问权限的成员检出与复现；Public 仍为 NO-GO。** 待历史清理、授权与独立复核后，另行发布经筛选的公开版。这个结论仅针对发布许可与隐私，并不否定其研究用途或上传完整性。
