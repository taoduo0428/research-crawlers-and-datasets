# 这个文件夹放什么

这里是**整个仓库共用的说明**，不属于某个单独的网站。

- [数据怎么读](DATA_GUIDE.md)：常见字段、怎么合并、哪些表不能相加。准备写分析代码时看它。
- [新同学怎么接手](RESEARCH_WORKFLOW.md)：下载、安装、提交代码和补交数据的步骤。
- [数据公开和使用问题](SECURITY_AND_LIMITATIONS.md)：旧 Git 历史、第三方内容、账号和个人信息的注意事项。
- [2026-10-17 仓库检查记录](REPOSITORY_AUDIT_2026-10-17.md)：当时每个网站有多少数据、哪些测试跑过、哪些问题还没解决。
- [写说明的习惯](WRITING_STYLE.md)：以后新增项目时，别再把 README 写成一份空泛的宣传稿。
- `optional-ci-workflow-template.yml`：GitHub Actions 的可选配置模板，**目前没有启用**；普通成员不需要处理。

如果想知道某一个网站**怎么运行爬虫**，请回[总 README](../README.md) 找那个网站的说明。这里主要解释全仓库的共同问题。
