# B站：视频信息和字幕

这里留着几次采集的代码和结果，主要是视频基本信息、字幕和封面。

## 文件在哪

- `source/main/`：第一批视频和字幕处理脚本，还有 `bilibili_API.ipynb`。
- `source/supplement/`：后来补充的字幕、视频信息和封面脚本。
- `data/第一次字幕/结果.csv`：第一批结果，3,259 行，其中 2,507 行有字幕。
- `data/结果.csv`：另一批 3,132 行，涉及 3,020 个不同 CID；里面有 112 个重复 CID。
- `data/supplement/`：补充的 Excel/CSV。
- `data/` 下其他 CSV：键盘、手环等主题视频的信息。

两批主表合起来是 **4,904 个不同 CID**，其中 **3,667 个至少有一份非空字幕**。但它们有重叠，也有少量相同 CID 对应不同字幕文本的情况。

## 继续做的时候

先按 `CID` 合并，优先保留有字幕的版本，再单独查看内容冲突。不要把几个 CSV 的行数直接加成视频数。

代码是不同时间写的，有些用了旧 API 或 Windows 绝对路径。需要重新采集的话，先调整路径、验证网站返回字段，再做小样本测试。已有字幕和视频资料属于第三方内容，转发或发布前请确认权限。
