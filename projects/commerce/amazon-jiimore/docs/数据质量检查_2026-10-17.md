# Amazon + Jiimore：数据质量检查记录

检查日期：**2026-10-17**。这次检查的是已经放在 GitHub 的真实 CSV，不是实时访问 Amazon、Jiimore 或 SellerSprite。目的是确认哪些表能用、关联时按什么字段、哪里不能偷偷去重。

## 各张表的规模

| 数据 | 行数 | 有效 ASIN 数 | 时间范围 |
| --- | ---: | ---: | --- |
| 商品信息 `products.csv` | 2,006 | 1,999 | 商品快照，无统一采集时间列 |
| 标签 `tags.csv` | 8,533 | 1,342 | 无时间列 |
| ASIN 清单 `asin.csv` | 1,999 | 1,999 | 无采集时间列 |
| 周点击 `weekly_clicks.csv` | 117,049 | 1,999 | 2023-01-08～2024-04-07 |
| 月销量 `monthly_sales.csv` | 66,871 | 1,998 | 2017-05～2024-04 |

| Keepa `keepa_history.csv` | 25,824 | 18 | 2011-03-25～2024-04-17 |

四张主表（商品、周点击、月销量、月评论）共有 **1,998 个共同 ASIN**。商品表有 7 行 ASIN 为空；月销量有 104 行 ASIN 为空。**这些行没有可靠的关联键，应单独留着检查，不要按行号拼进去。**

## 重复与缺失，最需要注意的地方

- 月销量的有效 `ASIN + 月份` 键有 **64,503 组**；重复的有效键记录 **2,264 行**，其中 **28 组**存在不同值。完全相同的重复行可以在分析副本里收敛到一条；有不同值的必须保留候选记录待核对。
- 月评论的有效 `ASIN + 月份` 键有 **173,913 组**；重复记录 **4,872 行**，有 **1 组**字段值冲突。
- 月销量 `月销量` 字段缺 6,134 行；`月销售额`、`平均单价` 各缺 6,159 行。
- 月评论 `评分数增长值` 缺 129,008 行；`留评率` 缺 130,399 行。空值不能直接解释成 0。
- 商品信息的 `标题` 缺 792 行，`amazon global shipping` **2,006 行全空**。这说明旧的运费补采脚本并没有在这份发布数据中形成可用结果。
- Keepa 仅覆盖 18 个 ASIN，不具备覆盖整个样本的条件。

## 我们实际跑了什么

新增的 `../tools/review_data.py` 完全离线，不使用第三方账号。它有三个功能：

- `audit`：逐行核对 7 张原始 CSV 的主键、空值、重复和覆盖范围，不改数据。
- `merge-monthly`：按 `ASIN + 月份` 外连接月销量和月评论，生成 **175,911 行**月度关联表；其中遇到冲突键，数值留空并写 `冲突待核对`，另生成冲突明细 CSV。
- `export-asin`：给一个真实 ASIN，从 7 张源表分别筛出这个商品的记录。表之间**不会按行号或行数直接连接**。

真实文件测试得到：

| 验证项 | 结果 |
| --- | --- |
| 月度关联表 | **175,911 行**，涉及 1,999 个 ASIN |
| 不同值的销量冲突 | **28 组键** |
| 不同值的评论冲突 | **1 组键** |
| 冲突明细 | 58 行候选值，供人核对 |
| 月销量无有效键 | 104 行，没有拼入关联表 |
| 单 ASIN `B09XMYFTB7` 导出 | 七张表均可按 ASIN 过滤，保持各自原字段 |
| 文件完整性 | 参与检查的源 CSV 的 SHA-256 前后相同 |

月度关联表是「每个 ASIN、每个月最多一行」的**外连接分析副本**。比如某商品在 2017 年有评论数据但没有销量，这个月依然留在表里，销量状态为 `无该月份`。缺失、不存在和冲突是不同情况。

这些输出在验证时保存到临时目录，**没有把关联表当成新的原始数据再提交到仓库**。谁要使用就自己运行命令生成，并保留当次检查记录。

## 以后怎么做分析

先确认研究问题。如果是研究长期月度销量及评论，使用 `merge-monthly` 的结果；如果还要加 Jiimore 周点击，先明确要怎么转成月度数据，再按 `ASIN + 月份` 关联，别直接按 ASIN 放大行数。要看单个商品的真实材料，使用 `export-asin`，逐张源表检查最清楚。

最后要说明：这轮只验证**历史数据的完整性、关联方式和离线代码**。旧的网页登录与采集 API 能不能继续工作，需要另外在当前网站上进行授权环境的小样本测试。
