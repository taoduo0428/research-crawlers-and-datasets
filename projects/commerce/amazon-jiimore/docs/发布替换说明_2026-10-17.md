## 哪些东西绝不能公开

整理版本机具有**真实配置** `config.local.json`、`sellersprite_cookies.json`，还含 **`.edge-amazon-profile/`** 浏览器资料，可能保存账号会话、插件状态、用户设备数据。全部**没有复制**，并由 `.gitignore` 禁止跟踪。

本机 `data/amazon/reviews.csv`、`goods_infos.csv`、`last_run.json`，以及 `data/jiimore/`、`data/sellersprite/` 的新运行结果不发布。理由：真实评论用户名称、第三方文本、账号订阅所得数据及可识别的运行记录需要单独评估可公开性；仓库既有历史研究表则维持原状。只发布 `source/data/ASIN.txt` 作为公开标识的测试输入。

## 需要注意的功能口径

- 整理版 `jiimore.py` 实际通过 `categoryId` 分页取 ASIN，**不会返回完整商品历史周点击值**：当前 `jiimore.csv` 的点击/日期为空。此前旧版 `weekly_clicks.csv` 是另一批历史结果，不可冒充新版功能。
- 浏览器登录状态与 `requests` Session 分离。用户 Edge 登录 Jiimore 或 SellerSprite 插件，不能证明对应独立 API 现在已有权访问。
- `amazon.py` 默认只运行两个测试 ASIN；使用 `--asin-file` 配合 `--limit` 才会批量选择输入列表，遇到页面限制会暂停并保留已采结果。
- 月销量接口返回空响应不能视为成功。SellerSprite 评论增长与 Keepa 也需逐批检查数据/日期质量。
