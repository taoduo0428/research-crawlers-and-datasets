# 外包网站的数据放在哪

这组一共四个站。**爬虫代码集中放在[共用工程](../market-platform/README.md)**，这里放的是按网站整理的结果和使用说明。

| 网站 | 数据在哪 | 目前是什么情况 |
| --- | --- | --- |
| [一品威客](epwk/README.md) | `epwk/data/` | 旧版 2,691 条；补充采集并审核 1,997 条，还有几个筛选子集 |
| [猪八戒](zbj/README.md) | `zbj/data/records.csv` | 7,082 条任务，主要是列表里的信息 |
| [实现网](shixian/README.md) | `shixian/data/records.csv` | 53 条，其中有 7 条是全职岗位 |
| [程序员客栈](proginn/README.md) | 暂无正式数据表 | 有代码，尚未确认一批可交付结果 |

如果你要研究项目价格，先确认那个数字是**任务预算、协商报价还是人才日薪/月薪**。几个网站的字段看着像，业务含义未必一样。

一品威客还有一件容易弄错的事：1,200 条 A/B 样本、956 条价格优先样本，都是从 1,997 条审核主表里筛出来的，不是新抓的两批数据。

想重新抓取，进入 `../market-platform/`，用 `python run.py --help` 查当前命令，再看具体站点的 README。
