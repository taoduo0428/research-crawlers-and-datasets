# 招聘数据：BOSS、前程无忧、猎聘

三个网站的数据分开放，采集代码主要在[共用工程](../market-platform/README.md)，前程无忧和猎聘还有自己的独立子工程。

| 网站 | 已有结果 | 数据位置 |
| --- | ---: | --- |
| [BOSS直聘](boss/README.md) | 39,594 条最终结果 | `boss/data/` |
| [前程无忧](job51/README.md) | 27,552 条最终结果 | `job51/data/` |
| [猎聘](liepin/README.md) | 46,607 条最终结果，49,056 条源层 | `liepin/data/` |

三站的 `final.csv` 采用相同的六列：

`职位、JD、薪资、一级分类、二级分类、三级分类`。

做基础的岗位文本分析比较方便，但这六列**没有公司、原始岗位 ID 和详情链接**。不能根据行号去拼源表，也不要只因为两条岗位文案一样就删掉其中一条。

需要追溯采集来源时，优先看源数据。BOSS 目前只有岗位 ID 的归档表，前程无忧的完整原始层尚未恢复，猎聘有 `full-source.csv`。具体差别写在各站 README 中。

数据是历史采集结果，不代表今天还在招聘的职位。
